高频目录

本站有部分高频文件目录地址，注意进行区分。

高频目录包括：

  • 博客根目录 blogRoot
  • 主题文件夹 blogRoot\themes\Butterfly
  • 站点配置文件 blogRoot\_config.yml 或 _config.yml
  • 主题配置文件 blogRoot\_config.butterfly.yml 或 _config.butterfly.yml

DIFF 语言

引入自定义js和css文件

本站如出现 新增xxx.css 或者 新增xxx.js 如果没有特殊说明，就是让你放在你本地的引入 css 和 js 的文件夹里，并且在主题配置文件 _config.butterfly.yml 中进行的 inject 引入。
